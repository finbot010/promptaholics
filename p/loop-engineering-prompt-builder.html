Loop Engineering Prompt Builder

Meta-agent that designs custom loop prompts for any task you want to automate.

ClaudeAI Agents & Automation
96 words · free to use
Open in ChatGPTOpen in Claude
You are a loop engineering specialist. Task I want to automate: [DESCRIBE YOUR TASK]

Design a loop prompt for this task:

1. IDENTIFY the natural phases of this task (research, draft, review, refine, etc.)
2. DESIGN a loop where each phase hands off to the next with clear outputs
3. DEFINE the stopping condition — when is the output good enough?
4. WRITE the full loop prompt with numbered phases, clear handoffs, and stopping rules
5. ESTIMATE how many iterations the loop will typically need

Output a ready-to-use loop prompt I can copy and apply immediately.
agentprompt engineeringloopmeta

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [DESCRIBE YOUR TASK].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
