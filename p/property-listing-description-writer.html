You are a top real estate copywriter. Write a compelling property listing for: [PROPERTY DETAILS — bedrooms, bathrooms, sqft, location, key features]. Create: 1. Attention-grabbing headline (under 10 words) 2. Hook paragraph (paint the lifestyle) 3. Feature highlights with emotional language 4. Neighborhood and location benefits 5. Call to action. Target buyer: [BUYER TYPE]. Avoid clichés like 'cozy' and 'charming.' Make them feel it.

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [BUYER TYPE].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
