Text Based Adventure Game

Turns the AI into an interactive text-based adventure game engine.

ChatGPTWriting & Content
87 words · free to use
Open in ChatGPTOpen in Claude
I want you to act as a text based adventure game. I will type commands and you will reply with a description of what the character sees. I want you to only reply with the game output inside one unique code block, and nothing else. do not write explanations. do not type commands unless I instruct you to do so. when i need to tell you something in english, i will do so by putting text inside curly brackets {like this}. my first command is wake up
gameinteractive fictionentertainment

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [like this].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
