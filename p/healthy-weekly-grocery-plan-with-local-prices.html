Healthy Weekly Grocery Plan With Local Prices

Builds a balanced weekly grocery list for your budget using current prices from stores near you.

GeminiHealth & Wellness
94 words · free to use
Open in ChatGPTOpen in Claude
Build a healthy weekly grocery plan for me using current prices where you can find them.

Location: [CITY / ZIP]
People: [NUMBER, AGES]
Budget: [AMOUNT PER WEEK]
Dietary needs: [VEGETARIAN / ALLERGIES / NONE]
Stores I can reach: [STORE NAMES]
Cooking time per day: [MINUTES]

Give me: a grocery list by store section with estimated prices; 7 simple dinners and 3 breakfast/lunch options using those ingredients; how to use leftovers so nothing is wasted; and where to save money. Note that prices change and should be checked in store or on the store's app.
grocerieshealthy eatingbudget

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [CITY / ZIP], [NUMBER, AGES], [AMOUNT PER WEEK], [VEGETARIAN / ALLERGIES / NONE], [STORE NAMES], [MINUTES].
  3. Paste it into Gemini and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
