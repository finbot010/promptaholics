Write a Python script that automates the following task:

Task: [DESCRIBE EXACTLY WHAT YOU WANT TO AUTOMATE]
Input: [WHAT DATA/FILES GO IN]
Desired output: [WHAT SHOULD COME OUT]
Frequency: [HOW OFTEN WILL THIS RUN]
Environment: [MAC/WINDOWS/LINUX]
Libraries I can use: [ANY PREFERENCES OR RESTRICTIONS]

Provide:
1. The complete, working script with comments
2. Required library installations (pip commands)
3. How to run it
4. How to schedule it to run automatically
5. Error handling for the most likely failure points
6. How to modify it for [SLIGHT VARIATION]

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [DESCRIBE EXACTLY WHAT YOU WANT TO AUTOMATE], [WHAT DATA/FILES GO IN], [WHAT SHOULD COME OUT], [HOW OFTEN WILL THIS RUN], [MAC/WINDOWS/LINUX], [ANY PREFERENCES OR RESTRICTIONS], [SLIGHT VARIATION].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
