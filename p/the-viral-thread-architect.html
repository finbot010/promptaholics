The Viral Thread Architect

10-tweet viral thread with scroll-stopping hook, punchy insights, pattern interrupts, and a strong CTA.

ChatGPTWriting & Content
86 words · free to use
Open in ChatGPTOpen in Claude
Build a 10-tweet thread on [TOPIC] designed to go viral. The first tweet must be an irresistible hook that stops the scroll — use a bold claim, surprising stat, or contrarian take. Each subsequent tweet should deliver one punchy insight that builds on the last. Use short sentences. Add white space. Include 2 pattern interrupts (a metaphor and a 'here's the thing' pivot). End with a powerful CTA that drives engagement. Write it so each tweet stands alone but the full thread tells a complete story.

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [TOPIC].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
