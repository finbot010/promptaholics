Database Migration Planner

Plans a zero-downtime database schema change with forward and rollback scripts.

ClaudeCode & Tech
98 words · free to use
Open in ChatGPTOpen in Claude
Plan a safe database migration.

Database: [POSTGRES / MYSQL / SQLITE / FIRESTORE]
Current schema (relevant tables):
[PASTE]
Change I need: [e.g. split name into first/last, add NOT NULL column, rename table]
Table sizes: [APPROX ROWS]
Downtime allowed: [NONE / A FEW MINUTES]

Give me:
1. Risks of doing it the naive way.
2. A step-by-step expand/contract plan that keeps the app working throughout.
3. Forward migration scripts for each step.
4. Backfill script that runs in batches.
5. Rollback script for each step.
6. App code changes needed between steps.
7. How to verify each step worked.
databasemigrationsql

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [POSTGRES / MYSQL / SQLITE / FIRESTORE], [PASTE], [APPROX ROWS], [NONE / A FEW MINUTES].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
