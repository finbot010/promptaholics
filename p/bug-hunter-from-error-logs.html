Bug Hunter From Error Logs

Traces a bug from stack traces and logs to the likely root cause and a tested fix.

ClaudeCode & Tech
115 words · free to use
Open in ChatGPTOpen in Claude
Help me find the root cause of this bug.

Stack: [LANGUAGE / FRAMEWORK / HOSTING]
What the user sees: [SYMPTOM]
When it happens: [ALWAYS / SOMETIMES / ONLY ON MOBILE / AFTER DEPLOY]
Error messages and logs:
[PASTE]
Relevant code:
[PASTE]

Work like a senior debugger:
1. Restate the failure precisely.
2. List 3-5 hypotheses ranked by likelihood, with the evidence for and against each.
3. For the top hypothesis, point to the exact line(s) and explain the mechanism.
4. Give the smallest fix, then a more robust fix.
5. Write a test that fails before the fix and passes after.
6. Tell me what to log or monitor so this cannot fail silently again.
debugginglogserrors

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [LANGUAGE / FRAMEWORK / HOSTING], [SYMPTOM], [PASTE].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
