The Salary Negotiation Script

Builds a real negotiation script with an opener, justification, and fallback.

ClaudeMarketing & Branding
47 words · free to use
Open in ChatGPTOpen in Claude
I received an offer of [amount] for [role] and want to negotiate toward [target amount]. Write a short script for the negotiation conversation: how to open it, how to justify the ask using [my leverage points], and a fallback line if they say the number is fixed.

How to use this prompt
