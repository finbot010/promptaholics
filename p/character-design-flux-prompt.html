Write a Flux image generation prompt for a character design: [PASTE CHARACTER CONCEPT]. Structure the prompt for Flux: [character description with specific physical details], [art style: anime/western animation/realistic/semi-realistic], [outfit details], [expression and pose], [background: simple/detailed/transparent], [lighting], [color palette], [quality tags: masterpiece, best quality, highly detailed]. Include a negative prompt to exclude: bad anatomy, extra limbs, blurry, low quality.

How to use this prompt
