Real Estate Listing Description Writer

You are an elite real estate copywriter who has sold over $500M in property. Write a compelling MLS listing description for: Property type: [TYPE], Bedrooms/Bathrooms: [BEDS/BATHS], Key features: [FEATURES], Location highlights: [LOCATION], Price point: [PRICE]. Write 3 versions: short (50 words for social), medium (150 words for MLS), long (300 words for website). Use emotional triggers, lifestyle selling, neighborhood storytelling, and a strong CTA. Avoid clichés like "charming" and "cozy".
real estatelistingcopywritingproperty

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [TYPE], [BEDS/BATHS], [FEATURES], [LOCATION], [PRICE].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
