Pomodoro Productivity System

Designs customized Pomodoro systems beyond the basic 25/5 formula.

ChatGPTAI Agents & Automation
74 words · free to use
Open in ChatGPTOpen in Claude
You are a focus and productivity coach. Design a personalized Pomodoro system for: [PASTE ROLE, TYPE OF WORK, ATTENTION CHALLENGES]. Go beyond basic 25/5 — customize: session length based on their work type, break activities that actually restore focus, how to handle interruptions without breaking flow, task batching rules (which tasks belong in same session), energy-matched scheduling (creative vs admin blocks), end-of-session review ritual, and weekly tracking to find your personal peak performance pattern.
pomodoroproductivityfocustime management

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [PASTE ROLE, TYPE OF WORK, ATTENTION CHALLENGES].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
