Rental Listing Writer

Writes an accurate, appealing rental listing that answers tenant questions and follows fair housing rules.

ClaudeReal Estate
84 words · free to use
Open in ChatGPTOpen in Claude
Write a rental listing for my property. Follow fair housing rules: describe the property, not the kind of person who should live there.

Property: [TYPE, BEDS, BATHS, SIZE]
Location and nearby: [NEIGHBORHOOD, TRANSIT, SHOPS, SCHOOLS]
Rent, deposit, lease length: [DETAILS]
Included: [UTILITIES, PARKING, APPLIANCES]
Rules: [PETS, SMOKING]
Best features: [LIST]
Available from: [DATE]

Give me: 3 headline options; a listing description (about 200 words); a bullet list of facts; a short version for social media; and a list of photos to take, in order.
rental listinglandlordcopywriting

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [TYPE, BEDS, BATHS, SIZE], [NEIGHBORHOOD, TRANSIT, SHOPS, SCHOOLS], [DETAILS], [UTILITIES, PARKING, APPLIANCES], [PETS, SMOKING], [LIST], [DATE].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
