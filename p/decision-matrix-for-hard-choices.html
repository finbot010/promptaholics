Decision Matrix for Hard Choices

Builds a weighted decision matrix for a hard choice and stress-tests the result.

ClaudeAI Agents & Automation
100 words · free to use
Open in ChatGPTOpen in Claude
Help me make this decision with a weighted decision matrix.

Decision: [WHAT YOU ARE DECIDING]
Options: [LIST]
What matters to me: [CRITERIA]
Deadline to decide: [DATE]

1. Help me weight the criteria (ask me if something is unclear).
2. Score each option 1-10 on each criterion, explaining each score, using what I have told you.
3. Show the weighted totals.
4. Stress test: what would have to be true for the losing option to win?
5. Regret check: which choice would I most regret in 5 years, and why?
6. A clear recommendation and the next step to take today.
decision makingpros and consmatrix

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [WHAT YOU ARE DECIDING], [LIST], [CRITERIA], [DATE].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
