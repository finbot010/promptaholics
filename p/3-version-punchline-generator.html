3-Version Punchline Generator

Background: YouTube audiences have short attention spans and need humor injected

Background: YouTube audiences have short attention spans and need humor injected frequently to stay engaged. Objective: Transform [ORIGINAL SCRIPT LINE] into a line with a clear comedic setup and satisfying punchline or payoff. Output: Write 3 versions of the rewritten line each using a different punchline style: 1) Callback punchline referencing something universal 2) Anti-climax punchline that deflates expectations 3) Escalation punchline that goes bigger and wilder. Steps: First write the boring original analysis in one sentence then deliver each rewrite clearly labeled. Target: The final lines should feel like something a charismatic YouTuber would actually say naturally on camera.
