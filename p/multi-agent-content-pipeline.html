Multi-Agent Content Pipeline

4-agent pipeline: researcher, strategist, writer and editor work in sequence to produce polished content.

ClaudeAI Agents & Automation
111 words · free to use
Open in ChatGPTOpen in Claude
Run a multi-agent content pipeline for: [YOUR TOPIC]

AGENT 1 — RESEARCHER: Find the 5 most important facts, statistics, and insights about this topic. Cite sources where possible.

AGENT 2 — STRATEGIST: Based on the research, what is the most compelling angle? What does the audience actually care about? What is the hook?

AGENT 3 — WRITER: Using the research and strategy, write the full content piece. Follow this structure: [HOOK → PROBLEM → INSIGHT → EVIDENCE → TAKEAWAY]

AGENT 4 — EDITOR: Review the draft. Tighten every paragraph. Cut the weakest 20%. Output the final version.

Each agent hands off to the next. Output all 4 agents' work in sequence.
agentcontentpipelineloopwriting

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [YOUR TOPIC], [HOOK → PROBLEM → INSIGHT → EVIDENCE → TAKEAWAY].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
