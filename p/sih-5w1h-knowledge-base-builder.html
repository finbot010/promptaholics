SIH 5W1H Knowledge Base Builder

Act as a research database compiler. Build a comprehensive knowledge base docume

Act as a research database compiler. Build a comprehensive knowledge base document for Smart India Hackathon (SIH) winner and runner-up projects covering the last 5 editions ([YEAR_RANGE]). For EACH winning and runner-up team entry, extract and document the following using the 5W1H framework: WHO: Team name, team members count, mentor name, institution name, city, state WHAT: Project name, project description (100-150 words), problem statement title, PS code WHERE: SIH edition venue/mode (online/offline), grand finale location WHEN: Year and edition of SIH WHY: Problem being solved, social/economic impact, target beneficiaries HOW: Technology used, methodology, prototype stage, deployment status. Additionally include: Key Innovation Point, Awards & Recognition, Post-SIH development status (if project was commercialized or adopted by government). Format as a structured database with [CATEGORY_FILTER] options for easy retrieval. Summarize top 3 key takeaways from each year at the end.

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [YEAR_RANGE], [CATEGORY_FILTER].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
