Decision Tree Agent

Builds a visual decision tree for any decision and highlights the recommended path.

ClaudeAI Agents & Automation
113 words · free to use
Open in ChatGPTOpen in Claude
You are a decision tree agent. Decision to make: [YOUR DECISION]

Build a decision tree:

NODE 1 — What is the core question that determines everything else? State it clearly.

BRANCH A — If answer is YES/Option A: what are the next 2-3 decisions that follow?
BRANCH B — If answer is NO/Option B: what are the next 2-3 decisions that follow?

For each branch, repeat one level deeper — what decisions does each answer unlock?

TERMINAL NODES — At the end of each branch, what is the final outcome or action?

Output the full decision tree visually using indentation, then highlight the path you recommend based on [MY SITUATION: describe your situation].

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [YOUR DECISION], [MY SITUATION: describe your situation].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
