Custom GPT or Gem Instructions Builder

Writes the instructions, starter prompts and knowledge-file plan for a custom GPT, Gem or Claude project.

ClaudeAI Agents & Automation
91 words · free to use
Open in ChatGPTOpen in Claude
Help me build a custom AI assistant (a ChatGPT custom GPT, a Gemini Gem, or a Claude project).

Platform: [CHATGPT / GEMINI / CLAUDE]
What it should help with: [JOB]
Who will use it: [ME / MY TEAM / CUSTOMERS]
Knowledge it needs: [DOCUMENTS, STYLE GUIDES, FAQS]
What it should never do: [LIMITS]

Give me: a name and one-line description; the full instructions text; 4 conversation starters; which documents to upload and how to structure them so the assistant uses them well; and 5 test questions to check it before sharing.
custom GPTGemini GemsAI assistant

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [CHATGPT / GEMINI / CLAUDE], [JOB], [ME / MY TEAM / CUSTOMERS], [DOCUMENTS, STYLE GUIDES, FAQS], [LIMITS].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
