You are a Creative Director and brand identity expert at a top-tier global design agency. Apply Design Thinking methodology to develop a complete visual identity direction for [BUSINESS NAME] in the [INDUSTRY] industry.

EMPATHIZE: The target audience is [TARGET AUDIENCE DESCRIPTION] who feel [EMOTIONAL STATE] and desire [ASPIRATION].
DEFINE: The brand must visually communicate [3 CORE BRAND ATTRIBUTES].

DELIVER THE FOLLOWING:

1. COLOR PSYCHOLOGY SYSTEM
- Primary palette (2 colors): HEX codes + RGB values + psychological rationale
- Secondary palette (3 colors): HEX codes + usage rules
- Accent/action color (1): For CTAs and highlights
- For EACH color provide:
  a) Psychological meaning in the [INDUSTRY] context
  b) Cultural considerations for [TARGET MARKETS]
  c) Emotional response triggered
  d) Competitor color gap analysis (why this color is ownable)
- Light mode and dark mode palette specifications
- Accessibility compliance notes (WCAG 2.1 AA minimum)

2. TYPOGRAPHY DIRECTION
- Primary typeface: Name, classification, personality, and usage rules
- Secondary typeface: For body copy and supporting text
- Accent typeface (optional): For campaign-specific use
- Type scale system (H1 through body and caption)
- Typography DO and DON'T examples (5 each)
- Recommended Google Fonts or Adobe Fonts alternatives

3. LOGO DIRECTION BRIEF
- 3 distinct logo concept directions (not the actual logo, but written creative briefs)
- Each brief includes: design metaphor, shape language, color application, and cultural symbolism
- Recommended direction with rationale

4. VISUAL LANGUAGE & IMAGERY STYLE
- Photography style guide (5 rules)
- Illustration style direction
- Icon system personality
- Pattern and texture usage
- Motion/animation principles (3 core principles)

5. BRAND APPLICATIONS PREVIEW
- Describe how the visual identity applies to: Business card, Website hero, Social media profile, Packaging (if relevant), Outdoor advertising

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [BUSINESS NAME], [INDUSTRY], [TARGET AUDIENCE DESCRIPTION], [EMOTIONAL STATE], [ASPIRATION], [3 CORE BRAND ATTRIBUTES], [TARGET MARKETS].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
