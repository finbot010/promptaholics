Social Media Manager Agent

Social media manager creates a complete week of platform-native content with exact copy, posting times, engagement hooks, and comment reply templates.

ChatGPTAI Agents & Automation
94 words · free to use
Open in ChatGPTOpen in Claude
Act as my social media manager for [BRAND / PERSONAL BRAND]. Platforms: [LIST PLATFORMS]. Here is what I want to communicate this week: [BRIEF — product launch / insight / story / announcement / promotion]. Create a complete week of platform-native content: for each platform produce the exact post copy adapted for that platform's culture, the optimal posting time, the content format recommendation, the engagement hook, and the reply strategy for the first hour. Also provide 5 comment reply templates for common responses. Make each post feel native to its platform — not copy-pasted.
social mediaagentcontentschedulingstrategymanagement

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [BRAND / PERSONAL BRAND], [LIST PLATFORMS].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
