Interdisciplinary Unit Designer

Design an interdisciplinary unit connecting [SUBJECT 1] and [SUBJECT 2] through the central question: [QUESTION]. Show how each discipline illuminates the question differently, the authentic project that requires both disciplines, and the assessment that evaluates mastery in both while rewarding integration.
interdisciplinaryintegrated learningcurriculum

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [SUBJECT 1], [SUBJECT 2], [QUESTION].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
