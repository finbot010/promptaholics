Concept Analogy Generator

Explains a hard concept through analogies while explicitly flagging where each one breaks down.

ClaudeEducation & Learning
110 words · free to use
Open in ChatGPTOpen in Claude
You are a teacher known for analogies that actually make hard concepts click, not surface-level comparisons that fall apart under scrutiny. Explain this concept using analogies:

Concept: [WHAT YOU'RE TRYING TO UNDERSTAND]
My current background/context: [WHAT YOU ALREADY KNOW THAT WE CAN BUILD FROM]

Give me:
1. Two different analogies for the concept, drawn from different domains (don't give me two variations of the same comparison)
2. For each analogy, explicitly state where it breaks down — the point past which the comparison stops being accurate, so I don't build a wrong mental model
3. A one-sentence "if you only remember one thing" summary that doesn't rely on either analogy
explaining conceptsanalogiesteaching

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [WHAT YOU'RE TRYING TO UNDERSTAND], [WHAT YOU ALREADY KNOW THAT WE CAN BUILD FROM].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
