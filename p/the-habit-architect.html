The Habit Architect

Science-backed habit plan using stacking, the 2-minute rule, environment design, and 30/60/90 progression.

ChatGPTHealth & Wellness
131 words · free to use
Open in ChatGPTOpen in Claude
I want to build these new habits: [LIST 3-5 DESIRED HABITS]. Design a science-backed habit implementation plan using: (1) Habit Stacking — attach each new habit to an existing routine, show me exactly where it fits in my day, (2) The 2-Minute Rule — a stripped-down starter version of each habit so small I can't say no, (3) Environment Design — specific changes to my physical space that make each habit easier, (4) Tracking System — a simple daily tracker template with streaks and milestones, (5) Reward Protocol — immediate rewards that reinforce the behavior, (6) Failure Plan — what to do when I miss a day, (7) 30/60/90 Day Progression — how each habit evolves over 3 months. Include the psychology behind each strategy so I understand WHY it works.

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [LIST 3-5 DESIRED HABITS].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
