The Custom AI Agent Builder

Complete custom AI agent with system prompt, decision tree, response templates, escalation rules, and testing plan.

ChatGPTAI Agents & Automation★ Featured

Open in ChatGPTOpen in Claude
Build a complete custom AI agent for [USE CASE — customer support / sales / research / coaching / content creation]. Include: (1) System Prompt — a detailed persona definition with name, expertise, communication style, and behavioral rules, (2) Knowledge Boundaries — what the agent should and shouldn't discuss, (3) Conversation Flow — a decision tree for the 5 most common user interactions, (4) Response Templates — 10 pre-built response patterns for frequent scenarios, (5) Escalation Rules — when and how to hand off to a human, (6) Tone Guide — 3 example responses showing the exact voice, (7) Testing Scenarios — 5 edge cases with expected ideal responses, (8) Iteration Framework — how to review conversations and improve the agent weekly.
