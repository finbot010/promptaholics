Multi-Source Fact Verifier

Fact-checks a claim against current sources before you use it publicly.

GeminiEducation & Learning
125 words · free to use
Open in ChatGPTOpen in Claude
I need to verify a claim before I use it publicly. Using current, real information:

1. State whether the claim is accurate, partially accurate, outdated, or false
2. Cite the specific sources supporting your assessment
3. If the claim was true at some point but has changed (a statistic, a policy, a fact about a company), note when and what changed
4. Flag if this is a contested topic where reasonable sources disagree, rather than presenting one side as settled fact
5. Give me a corrected, accurately-sourced version of the claim I can actually use

The claim I want to verify: [STATE THE CLAIM]
Where I plan to use it: [E.G. A PRESENTATION, ARTICLE, SOCIAL POST - so you know how much precision I need]
fact-checkresearchverification

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [STATE THE CLAIM].
  3. Paste it into Gemini and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
