Creator Transformation Map

Map the complete transformation CREATOR delivers to their audience from starting point to end result. Starting point: WHERE THE AUDIENCE…

Map the complete transformation [CREATOR] delivers to their audience from starting point to end result. Starting point: [WHERE THE AUDIENCE BEGINS]. End result: [WHERE THE CREATOR TAKES THEM]. Build the transformation map with: 5-7 clear milestones along the journey, what the audience believes at each milestone, what they can do at each milestone, the emotional shift at each stage, the content type that serves each stage best, and the offer that fits each stage. Then write a transformation statement: 'I help [WHO] go from [STARTING POINT] to [END RESULT] using [METHOD].' This becomes the creator's core positioning statement.
creatortransformationaudiencejourney

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [CREATOR], [WHERE THE AUDIENCE BEGINS], [WHERE THE CREATOR TAKES THEM], [WHO], [STARTING POINT], [END RESULT], [METHOD].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
