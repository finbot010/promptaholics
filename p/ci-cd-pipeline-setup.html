Help me set up a CI/CD pipeline for my project.

Project type: [WEB APP/API/STATIC SITE]
Repository: [GITHUB/GITLAB]
Target environment: [AWS/VERCEL/NETLIFY/VPS]
Language/framework: [DESCRIBE]
Do you have tests: [YES/NO — what kind]

Design a pipeline that:
1. Triggers on push to main/PR
2. Runs linting and type checking
3. Runs test suite
4. Builds production bundle
5. Deploys to staging on PR, production on merge

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [WEB APP/API/STATIC SITE], [GITHUB/GITLAB], [AWS/VERCEL/NETLIFY/VPS], [DESCRIBE], [YES/NO — what kind].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
