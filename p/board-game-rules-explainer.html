Board Game Rules Explainer

Explains a board game's rules simply and creates a 5-minute teaching script for new players.

ClaudeLifestyle, Fun & Games
85 words · free to use
Open in ChatGPTOpen in Claude
Explain the rules of [GAME NAME] simply.

My group: [NEW PLAYERS / SOME EXPERIENCE]
Rulebook text or the parts we are confused about (if available): [PASTE]

Give me: the goal in one sentence; what happens on a turn; how you win; a 5-minute teaching script that teaches by playing a sample turn; common rules people get wrong; and answers to these questions: [YOUR QUESTIONS]. If I pasted rules, base everything on them; if not, tell me which details I should check in the official rulebook.
board gamesrulesteaching games

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [GAME NAME], [NEW PLAYERS / SOME EXPERIENCE], [PASTE], [YOUR QUESTIONS].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
