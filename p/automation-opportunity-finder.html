Automation Opportunity Finder

Reviews your weekly routine and finds tasks worth automating, with the tool and steps for each.

ClaudeAI Agents & Automation
81 words · free to use
Open in ChatGPTOpen in Claude
Find tasks I should automate.

My role: [ROLE]
Tools I use: [e.g. Gmail, Google Sheets, Notion, Slack, Stripe, Shopify]
My weekly tasks with rough time each: [LIST]
Budget for tools: [FREE ONLY / UP TO $X/MONTH]
Technical comfort: [NO CODE / SOME CODE]

For each task: whether it is worth automating (time saved vs setup effort), the best approach (built-in features, Zapier/Make, Apps Script, templates), and step-by-step setup. Rank by hours saved per month and start with the 3 easiest wins.
automationworkflowsno-code

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [ROLE], [LIST], [FREE ONLY / UP TO $X/MONTH], [NO CODE / SOME CODE].
  3. Paste it into Claude and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
