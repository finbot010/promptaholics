Build a complete REST API for [PROJECT DESCRIPTION] using [LANGUAGE/FRAMEWORK — Node.js/Express, Python/FastAPI, etc.]. Include: (1) Project structure — folder organization following best practices, (2) Database schema design with relationships, (3) All CRUD endpoints with proper HTTP methods, (4) Input validation and error handling middleware, (5) Authentication — JWT-based with refresh tokens, (6) Rate limiting and security headers, (7) Pagination for list endpoints, (8) Complete code for each file with detailed comments, (9) A Postman collection or curl commands to test every endpoint, (10) .env example file with all required variables.
