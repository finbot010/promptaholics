Flux Portrait Style Guide

Creates optimized Flux portrait prompts for different photography styles.

ChatGPTImage & Art
62 words · free to use
Open in ChatGPTOpen in Claude
Write optimized Flux image generation prompts for portrait photography styles: [PASTE STYLE OR MOOD: editorial/fine art/documentary/cinematic]. For each style create: subject description template, lighting description (quality, direction, color temperature), background and environment, camera and lens simulation, color grading direction, mood keywords, and negative prompt to exclude. Include 3 complete portrait prompts demonstrating different subjects in the same style. Add Flux-specific quality tags.

How to use this prompt
