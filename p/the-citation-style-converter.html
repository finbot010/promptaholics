The Citation Style Converter

Converts citations between academic styles and flags missing required fields.

33 words · free to use
Open in ChatGPTOpen in Claude
Convert this citation from [current style, e.g. APA] to [target style, e.g. MLA]: '[paste citation]'. If any required field is missing for the target style, tell me exactly what's missing instead of guessing.
citationsacademic writingapa mla

How to use this prompt

  1. Copy the prompt with the button above.
  2. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  3. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
