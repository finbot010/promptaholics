Agent Handoff Chain

5-agent handoff chain: analyst, strategist, executor, critic and finalizer work in sequence.

ClaudeAI Agents & Automation
115 words · free to use
Open in ChatGPTOpen in Claude
Run an agent handoff chain for this project: [DESCRIBE YOUR PROJECT OR PROBLEM]

AGENT 1 — ANALYST: Understand the problem. Define: what success looks like, what constraints exist, what information is missing.

AGENT 2 — STRATEGIST: Given the analysis, propose 3 possible approaches. For each: estimated effort, risk, and expected outcome.

AGENT 3 — EXECUTOR: Take the best approach and produce the actual deliverable. Go end to end.

AGENT 4 — CRITIC: Review the deliverable against the success criteria from Agent 1. What is missing? What is weak?

AGENT 5 — FINALIZER: Incorporate the critique and produce the final version. Note what was changed and why.

Each agent reads all previous agents' output before acting.
