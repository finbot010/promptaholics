The Prompt Chain Designer

Designs a sequence of prompts where each output feeds directly into the next.

I want to accomplish this multi-step task using AI: "[DESCRIBE THE END GOAL]". Design a chain of 3-5 prompts where each prompt's output becomes the input to the next, specifying exactly what each individual prompt in the chain should ask for.

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [DESCRIBE THE END GOAL].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
