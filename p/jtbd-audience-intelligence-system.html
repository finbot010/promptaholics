You are a consumer insights strategist and behavioral psychologist working for a global brand consultancy. Using the Jobs-to-Be-Done framework combined with Empathy Mapping, build a complete audience intelligence system for [BUSINESS NAME] in the [INDUSTRY] industry.

CONTEXT: [BUSINESS NAME] serves customers in [TARGET MARKETS/GEOGRAPHIES] with a product/service priced at [PRICE POINT/TIER].

DELIVER THE FOLLOWING:

1. AUDIENCE SEGMENTATION OVERVIEW
- Identify 4 distinct audience segments
- Map each on a 2x2 grid: [AXIS 1: e.g., Price Sensitivity] vs [AXIS 2: e.g., Brand Loyalty]
- Assign revenue priority (Primary/Secondary/Growth/Emerging) to each segment

2. DETAILED PERSONAS (create 3 full personas)
For each persona include:
- Name, age, location, occupation, income level
- FUNCTIONAL JOB: What task are they trying to complete?
- EMOTIONAL JOB: How do they want to feel?
- SOCIAL JOB: How do they want to be perceived by others?
- Pain points (5, ranked by intensity)
- Motivations (5, ranked by priority)
- Media consumption habits (platforms, content types, peak usage times)
- Purchase decision triggers and blockers
- Brand affinities (3 brands they love and why)
- A day-in-the-life narrative (150 words)
- Empathy map: Think/Feel | See | Hear | Say/Do | Pains | Gains
- Preferred communication style
- The ONE message that would make them choose [BUSINESS NAME]

3. AUDIENCE JOURNEY MAP
- Map all 3 personas through a 6-stage journey: Unaware → Aware → Curious → Evaluating → Committed → Advocating
- For each stage: emotional state, key question, preferred channel, brand action required

4. PSYCHOGRAPHIC CLUSTERS
- Values cluster analysis
- Lifestyle segmentation
- Cultural identity markers

5. ANTI-PERSONA
- Define who [BUSINESS NAME] is NOT for
- Explain the strategic value of this exclusion

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [BUSINESS NAME], [INDUSTRY], [TARGET MARKETS/GEOGRAPHIES], [PRICE POINT/TIER], [AXIS 1: e.g., Price Sensitivity], [AXIS 2: e.g., Brand Loyalty].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
