Seamless Pattern Designer

Generates seamless repeating patterns for fabric, wallpaper, packaging or print-on-demand products.

ChatGPTImage & Art
88 words · free to use
Open in ChatGPTOpen in Claude
Create a seamless repeating pattern.

Theme and motifs: [e.g. tropical leaves and lemons, tiny stars and moons, geometric tiles]
Style: [WATERCOLOR / FLAT VECTOR / HAND-DRAWN LINE / RETRO]
Colors: [PALETTE or 3-5 HEX CODES]
Density: [SPARSE / BALANCED / DENSE]
Use: [FABRIC / WALLPAPER / GIFT WRAP / PHONE CASE / T-SHIRT]

Make the tile repeat seamlessly on all four edges with no visible seams. Then make 2 color variations of the same pattern. Tell me how to test the repeat in an image editor before printing.
pattern designtextileprint on demand

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [PALETTE or 3-5 HEX CODES], [SPARSE / BALANCED / DENSE].
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
