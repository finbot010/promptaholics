AI System Prompt Designer

Builds custom AI personas and system prompts — essential for businesses using AI assistants, chatbots, and custom GPTs.

Design a custom system prompt for an AI assistant with the following personality and function:

Role: [WHAT THE AI WILL DO]
Personality traits: [3-5 TRAITS]
Tone: [HOW IT SHOULD COMMUNICATE]
Do's: [WHAT IT SHOULD ALWAYS DO]
Don'ts: [WHAT IT SHOULD NEVER DO]
Audience: [WHO WILL USE IT]
Specialty knowledge: [DOMAIN EXPERTISE]
Output format preferences: [HOW RESPONSES SHOULD BE STRUCTURED]

Create a system prompt that:
- Opens with the role definition
- Establishes personality with specific behavioral instructions
- Includes 3 example exchanges showing ideal behavior
- Has guardrails for edge cases
- Ends with a reminder of the primary goal

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [WHAT THE AI WILL DO], [3-5 TRAITS], [HOW IT SHOULD COMMUNICATE], [WHAT IT SHOULD ALWAYS DO], [WHAT IT SHOULD NEVER DO], [WHO WILL USE IT], [DOMAIN EXPERTISE], [HOW RESPONSES SHOULD BE STRUCTURED] and the rest.
  3. Paste it into ChatGPT, Claude or Gemini and send it.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
