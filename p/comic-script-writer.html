Comic Script Writer

Full comic book scripts in industry-standard format with panel descriptions, dialogue, and SFX.

ChatGPTImage & Art
83 words · free to use
Open in ChatGPTOpen in Claude
Write a comic book script for [STORY CONCEPT].

Genre: [SUPERHERO/HORROR/SLICE OF LIFE/SCI-FI/FANTASY]
Number of pages: [NUMBER]
Characters: [LIST WITH ONE-LINE DESCRIPTIONS]
Setting: [WHERE AND WHEN]
Tone: [DARK/LIGHT/SATIRICAL/EPIC]

Format each page:
PAGE [NUMBER] ([PANEL COUNT] panels)

PANEL [NUMBER]:
[VISUAL DESCRIPTION — what the artist draws]
[CHARACTER] (dialogue): 'Spoken text'
[CHARACTER] (caption): Inner monologue
SFX: Sound effects

Guidelines:
- Each panel drawable in one image
- Dialogue under 25 words per bubble
- Visual storytelling first
- End each page with a reason to turn

How to use this prompt

  1. Copy the prompt with the button above.
  2. Replace the parts in brackets with your own details: [STORY CONCEPT], [SUPERHERO/HORROR/SLICE OF LIFE/SCI-FI/FANTASY], [NUMBER], [LIST WITH ONE-LINE DESCRIPTIONS], [WHERE AND WHEN], [DARK/LIGHT/SATIRICAL/EPIC], [PANEL COUNT], [VISUAL DESCRIPTION — what the artist draws] and the rest.
  3. Paste it into ChatGPT and send it. It also works in other AI chat tools.
  4. Not quite right? Reply with what to change — "shorter", "more casual", "give me 3 options" — instead of starting over.
